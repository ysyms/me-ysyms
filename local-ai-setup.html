本地 AI 全套搭建教程

用 Ollama + SillyTavern 在 Windows 上跑本地无限制大模型，完整流程从零开始，跑通需要 20 分钟。

安装步骤
1
安装 Ollama
本地模型运行引擎

前往 ollama.com/download/windows 下载安装包，一路 Next 安装完成。

安装完成后打开命令提示符（Win+R → 输入 cmd）验证：

ollama --version

看到版本号说明安装成功，Ollama 默认在后台运行，监听 11434 端口。

2
下载模型
abliterated 无限制版本

在命令提示符中执行以下命令下载模型（约 17GB，建议挂代理）：

ollama pull huihui-ai/qwen2.5-abliterate:30b-a3b-q4_k_m

下载完成后测试一下是否能正常对话：

ollama run huihui-ai/qwen2.5-abliterate:30b-a3b-q4_k_m
显存说明：30B Q4 模型约 17GB，略超 16GB 显存，Ollama 会自动将少量 layer offload 到内存，性能影响极小。

其他可选模型对比：

模型 大小 显存占用 推荐
Qwen2.5-30B-A3B abliterated Q4 ~17GB 16GB + 少量 offload ★★★★★
Llama3.1-8B abliterated Q8 ~8.5GB 全显存 ★★★★
Qwen2.5-72B abliterated Q4 ~40GB 大量 offload ★★★
3
安装 Node.js
SillyTavern 的运行环境

前往 nodejs.org 下载 LTS 版本安装，全程默认选项即可。

安装后在命令提示符验证：

node --version

还需要安装 Git（如果没有）：

winget install Git.Git
4
安装 SillyTavern
AI 对话前端，支持角色扮演

在命令提示符中克隆仓库并启动：

git clone https://github.com/SillyTavern/SillyTavern
cd SillyTavern
Start.bat

首次运行会自动安装依赖，完成后浏览器自动打开 http://localhost:8000。

提示：以后每次启动只需双击 SillyTavern 文件夹里的 Start.bat，不需要重复执行上面的步骤。
5
连接 Ollama
完成最后配置

在 SillyTavern 界面中：

点击右上角 插头图标（API 连接） → API 类型选 Ollama → 服务器地址填：

http://127.0.0.1:11434

点击 连接，成功后从下拉菜单选择刚才下载的模型，开始对话。

连不上？确认 Ollama 在后台运行（系统托盘里有图标），或重新执行 ollama serve 启动服务。
